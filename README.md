# Introducing My Technical Interview Prep
This repo showcases the depth of my interview preparation for any behavioral or technical interview I might have. It is an ongoing process of answering questions the 6th edition "Cracking the Coding Interview" suggested answering and providing technical explanations, purpose driven answers, and practiced coded solutions in various languages for a variety of problems. Relevant information and suggestions from other online sources to suppliment my learning goals based on current industry needs will be added as needed. All technologies and sources used during this process are listed to the best of my knowledge below. This is intended to be used as an addition to my career portfolio but it can also be used as a resource for others like me grinding it out to land a grade A technical career in Computer Science.
